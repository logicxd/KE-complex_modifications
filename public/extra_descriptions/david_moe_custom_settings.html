David's Custom Settings

Personal set of IDE shortcuts for Xcode, Intellij, and Visual Studio Code (VSCode). Debug commands work with either the Right Control or Right Option key.

Debug Mapping (Right Control or Right Option)

Key Maps To
↓ Down Arrow Step Over
← Left Arrow Step Out
→ Right Arrow Step In
↵ Enter Continue

Other IDE Shortcuts (Right Control or Right Option)

Key Maps To
C Code Usages
B Re-run Last Build/Test
Delete Rename

Supported IDEs

  • Xcode
  • Intellij
  • Visual Studio Code (VSCode)
