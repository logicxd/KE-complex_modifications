Right Option to Debug in Various IDE

Use the same keyboard shortcuts to debug across various IDEs. Hold the Right Option key and press the other key to perform the action.

Mapping

Key Maps To
⌥ Right Option + ↓ Down Arrow Step Over
⌥ Right Option + ← Left Arrow Step Out
⌥ Right Option + → Right Arrow Step In
⌥ Right Option + ↵ Enter Continue

Supported IDEs

  • Xcode
  • Intellij
  • Visual Studio Code (VSCode)
